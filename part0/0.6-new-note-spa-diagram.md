# 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User writes text and clicks Save. The JavaScript onsubmit handler adds the note to the notes list and redraws the page (no page reload)

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa (JSON: {"content": "...", "date": "..."})
    activate server
    server-->>browser: 201 Created {"message":"note created"}
    deactivate server

    Note right of browser: The browser stays on the same page, no further requests are made
```
